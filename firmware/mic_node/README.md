# 마이크 노드 — 스피커 없는 보드를 센서로

이 보드에는 스피커가 붙어 있지 않다. 그래서 소리를 내는 쪽을 밖으로 뺐다:
보드는 마이크 2개로 감지만 하고, 소리와 화면은 태블릿이 맡는다.

## 실기에서 밝혀낸 것 — 공개 자료가 틀렸다

### 1. I2S DIN 은 GPIO35 가 아니라 **GPIO34** 다

널리 인용되는 ESP32-A1S 핀맵은 DIN=GPIO35 라고 한다. 이 보드에서는 **GPIO35 가 정확히
0 을 낸다.** 후보 핀을 순회해서 찾았다:

```
DIN=GPIO35 → 피크 0
DIN=GPIO34 → 피크 63    ← 신호 있음
DIN=GPIO39/36/23/22/19/18 → 피크 1 (노이즈 플로어)
```

나머지 핀(MCLK 0, BCLK 27, LRCK 25, DOUT 26)은 공개 정의와 일치했다. DIN 하나만 다르다.

### 2. AC101 라이브러리의 `MODE_ADC` 는 미완성이다

`Yveaux/AC101` 의 `SetMode()` 를 보면:

```cpp
if (MODE_LINE == mode) {
    WriteReg(ADC_SRC, 0x0408);        // 입력 소스 라우팅
    WriteReg(ADC_DIG_CTRL, 0x8000);   // ADC 디지털 인에이블
    WriteReg(ADC_APC_CTRL, 0x3bc0);   // 아날로그 경로 / PGA
}
if (MODE_ADC == mode || MODE_ADC_DAC == mode || MODE_LINE == mode) {
    WriteReg(MOD_CLK_ENA,  0x800c);   // 클럭만
    WriteReg(MOD_RST_CTRL, 0x800c);
}
```

**`MODE_ADC` 는 ADC 클럭만 켜고 디지털·아날로그 경로를 열지 않는다.** 저 세 레지스터는
`MODE_LINE` 에서만 쓴다. 그래서 마이크 입력이 통째로 죽는다. `begin()` 이 이미
`ADC_SRC=0x2020`(마이크)과 `ADC_SRCBST_CTRL=0xccc4`(부스트)를 써 두므로, 빠진 것은
경로 활성화 두 개다:

```cpp
codec.wr(0x40, 0x8000);   // ADC_DIG_CTRL
codec.wr(0x50, 0x3bc0);   // ADC_APC_CTRL
```

`ReadReg`/`WriteReg` 가 protected 라 서브클래스로 노출해야 한다.

### 3. 미해결 — 오른쪽 채널이 안 깨어난다

L 은 살아있고(피크 63 = 약 −54dBFS, 조용한 방의 노이즈 플로어에 부합) **R 은 피크 1** 이다.
`ADC_APC_CTRL` 후보 9개를 순회했지만 어느 값에서도 R 이 깨어나지 않았다.

다만 이 측정은 결론이 아니다. **소리를 낼 수단이 없어서** 전부 주변 소음에 의존했고,
방이 조용하면 "마이크가 죽음" 과 "마이크는 살았는데 조용함" 이 구분되지 않는다.
실제로 같은 `APC=0x3BC0` 이 1초 측정에서는 피크 63, 400ms 측정에서는 피크 1 로 나왔다.

**확정하려면 사람이 소리를 내는 동안 봐야 한다.** 펌웨어가 온셋을 누적 카운트하므로
손뼉을 치고 나중에 카운터를 읽으면 판정된다.

남은 의심: 마이크 1개만 실장 / 2번 마이크 경로에 다른 레지스터 필요 / 가운데 DIP 스위치.

### 4. 부수 발견 — K6(GPIO13)이 GPIO22 상태에 반응한다

신스 노드(GPIO22 를 출력 HIGH 로 구동)에서는 K6 이 LOW 로 읽혀 비활성됐고, 마이크
노드(GPIO22 미사용)에서는 정상 HIGH 다. 아까 관찰된 "빨간불" 과 같은 계열일 수 있다 —
GPIO22 가 앰프 인에이블이 아닐 가능성.

## 센싱 — PC 검증값

`mn_sense.c` 는 ESP-IDF 에 의존하지 않는 C99 라 gcc 로 합성 신호로 측정했다.

| 항목 | 결과 |
| --- | --- |
| **부화소 TDOA** | ±4 샘플 범위에서 **최대오차 0.011 샘플** |
| 잡음 내성 | SNR 9.5dB 이상에서 정확 (2.45~2.54 vs 실제 2.50) |
| 신뢰도 지표 | 실패 시 상관 0.095, 정상 0.5~0.9 → 게이트로 사용 가능 |
| DC 검출 | 주입 0.1831 vs 기대 0.183 |
| 온셋 | 손뼉 2회 → 정확히 2회 |

부화소 보간이 결정적이다. 정수 lag 만 쓰면 마이크 간격이 좁아 좌/중/우 3단이 끝인데,
0.011 샘플 해상도면 연속 컨트롤러가 된다.

마이크 간격을 모르므로 **각도로 환산하지 않고 지연(샘플)을 그대로 보고한다.**
모르는 값을 가정해 각도를 만들면 틀린 숫자가 맞는 것처럼 보인다.
